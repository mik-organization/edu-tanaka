# 四則演算APIの例外ハンドリング追加によるテスト仕様書
## はじめに
- サーバーを起動して、Talend API Testerを使ってテストを行う
- Json形式でリクエストを送る
- 四則演算APIに例外ハンドリングを追加

## 正常系
