# レジェンド検索「濁点」「半濁点」判別機能の実装のテスト仕様書

## レジェンド名の部分一致検索機能
### 正常系 レジェンド 部分一致検索
- 検索画面のテキストボックスに「ハ」と入力して、「検索」ボタンをクリック

   - [ ] エラーが表示されないこと。  
   - [ ] 指定した文字「ハ」を含んでいるレジェンドが表示されること。  
   - [ ] 濁点・半濁点の区別がされていること。「バ」と「パ」が表示されないこと。  

- 検索画面のテキストボックスに「バ」と入力して、「検索」ボタンをクリック

   - [ ] エラーが表示されないこと。  
   - [ ] 指定した文字「ハ」を含んでいるレジェンドが表示されること。  
   - [ ] 濁点・半濁点の区別がされていること。「ハ」と「パ」が表示されないこと。  

- 検索画面のテキストボックスに「パ」と入力して、「検索」ボタンをクリック

   - [ ] エラーが表示されないこと。  
   - [ ] 指定した文字「ハ」を含んでいるレジェンドが表示されること。  
   - [ ] 濁点・半濁点の区別がされていること。「ハ」と「バ」が表示されないこと。  

### 異常系 ひらがなで検索
- 検索画面のテキストボックスに「は」と入力して、「検索」ボタンをクリック

  - [ ] 該当レジェンドが表示されないこと  
 
### 異常系 英語で指定
- 検索画面のテキストボックスに「ha」と入力して、「検索」ボタンをクリック  

  - [ ] 該当のレジェンドが表示されないこと
